# Clase 2 · Separar los datos

El error de entrenamiento elige siempre el modelo más flexible. Esta clase
separa los datos para medir lo que no vemos: una parte para ajustar, otra
para elegir y otra que solo se abre al final; rota la validación entre
pliegues y descompone el error en ruido, sesgo y varianza.
