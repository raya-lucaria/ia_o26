# Clase 3 · Leer el error y regularizar

Un error se lee antes de cambiar nada: tres vistas de los residuales, un
benchmark y la pregunta de qué no ve el modelo. Cuando lo que sobra es
capacidad, se le pone un presupuesto a los coeficientes, y ese presupuesto
es un lagrangeano cuyo multiplicador es un hiperparámetro.
