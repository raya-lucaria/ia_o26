# Clase 1 · El problema

Existe una $f$ que no vemos y solo tenemos datos con ruido. Hay un error
que ningún modelo puede bajar, y el error de entrenamiento siempre miente a
nuestro favor. Esta clase plantea el problema, muestra que la representación
puede pesar más que el modelo y presenta la capacidad.
