# El proyecto del curso

Es un proyecto. **No es una tarea**: se presenta en persona, con la demo funcionando.

> [!WARNING]
> **ATENCIÓN: el día de la presentación está prohibido trabajar o hacer cualquier otra cosa mientras las demás personas exponen su proyecto. Pongan atención a sus compañeros.**

**Antes de la presentación, las entregas se cierran: ya no se hace merge.** Lo que esté entregado en ese momento es lo que se presenta.

::: table {#ia-proy-resumen title="El proyecto final"}

| | Proyecto final |
|---|---|
| Página | [El proyecto final](raya:proyecto-final) |
| Quién | Equipo de 1 o 2 (otro tamaño, hablarlo conmigo) |
| Dónde vive | Su carpeta en el [repositorio de entregas](https://github.com/raya-lucaria/ia_o26_proyecto_final), con Docker |
| Entrega | Dos pull requests: la propuesta, antes de empezar, y la entrega, el día del examen final |
| Carpeta | `estudiantes/<tu_equipo>/`, una por equipo |
| Paso a paso | [Cómo se entrega](raya:proyecto-final-entrega) |
| Se presenta | Con demo en vivo, platicando el proceso, de 8 a 12 minutos con reloj exacto |

:::

**El trabajo en GitHub es personal**: cada integrante hace sus commits con su propia cuenta, para que todo quede identificado por usuario de GitHub. Los pasos exactos están en [[proyecto-final-entrega|Cómo se entrega el proyecto final]] y en el [README del repositorio de entregas](https://github.com/raya-lucaria/ia_o26_proyecto_final/blob/main/README.md).

No se sube una presentación a GitHub. Con las entregas se arma una tabla ordenada con usuario, nombre y URL, y con ella se pasa a presentar de uno en uno.
