Justificación: con $c>0$, el bono de un hijo que deja de visitarse crece como $\sqrt{\ln N(s)}$ sin cota, así que ningún hijo queda sin visitas para siempre; con vueltas sin límite, cada nodo de un árbol finito se visita infinitas veces.
